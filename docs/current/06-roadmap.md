# 知伴 · 后续可优化点

> 反映当前真实状态（2026-08-20）。按优先级排序，标注状态。

## 1. 已明确的方向（长期演进）

这些是项目立项时就确定的长期目标，优先级低于 P0 主路径。

### 1.1 MCP 工具接入

**状态**：❌ 未开始。

当前工具是**内置的**（注册在 ToolRegistry），没有接入 MCP（Model Context Protocol）。

**目标**：接入 MCP client，支持动态挂载外部工具服务（查天气、真实联网搜索等），替代「每个工具都要写死在内置代码」的模式。

**前置**：MCP client 接入 + 协议适配。

### 1.2 ReAct 强化

**状态**：🟡 已有「有界 ReAct」，可进一步强化。

当前 ReAct 已有：最多 4 工具轮 + final round + 空回复/重复兜底 + 可观测（`agent.thinking` 事件）。

**可强化**：思考-行动-观察循环的更细粒度可配置、可视化。

### 1.3 主 Agent - Subagent 架构

**状态**：✅ 已实现（Memory/Task/Search 三个 subagent）。

**可扩展**：按需增加更多 subagent（如「内容创作 agent」「数据分析 agent」），复用 `ToolCallingSubAgent` 基类。
