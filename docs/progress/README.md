# 项目过程记录

本目录记录每个 Spec 的实际推进过程，面向项目复盘和答辩说明。它与 `specs/` 的区别：

- `specs/` 定义“应该实现什么、如何验收”。
- `docs/progress/` 记录“实际做了什么、验证了什么、还有什么问题”。

每份过程文档必须包含：

1. 对应 Spec 和当前状态。
2. 本次完成范围。
3. 关键决策及原因。
4. 新增或修改文件。
5. 实际执行的命令与结果摘要。
6. 未执行项及原因。
7. 已知风险和下一步。

更新规则：

- 每完成一个可独立验收的子步骤立即更新，不等整个阶段结束。
- 不把计划写成结果，不把 Mock 结果写成线上结果。
- 失败命令和环境缺失必须记录。
- 详细原始验证证据放在对应 `specs/NNN-*/verification.md`，本目录只保留摘要。
