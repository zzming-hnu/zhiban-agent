# 知伴 · 体验流程

> 反映当前真实实现（2026-08-20）。描述用户从打开到完成各类操作的完整路径。

## 1. 首次访问：注册与登录

```
打开 http://localhost:3000
  → 首页（品牌介绍 + 能力卡片）
  → 点击「登录 / 注册」
  → 登录页：输入邮箱 + 密码
     ├─ 已有账号 → 登录
     └─ 新用户 → 切换到「注册」→ 创建账号
  → 登录成功 → 自动跳转 /chat
```

## 2. 开始对话

```
聊天页（/chat）布局：
  ├─ 左侧栏
  │   ├─ 用户信息（昵称 + 邮箱）
  │   ├─ 「+ 新对话」按钮
  │   ├─ 对话列表（点击切换，悬停显示删除）
  │   ├─ 模型选择器（DeepSeek V4 Flash / Pro）
  │   └─ 导航：我的记忆 / 待办与提醒 / 退出登录
  └─ 主区域
      ├─ 消息流（用户右侧 / 助手左侧，Markdown 渲染）
      └─ 输入框（Enter 发送，Shift+Enter 换行）
```

## 3. 典型对话体验

### 3.1 闲聊

```
输入「你好」→ Enter
  → 主 Agent 直接回答（不委派）
  → 流式输出 Markdown 文本
```

### 3.2 创建待办

```
输入「帮我记个待办：明天交周报」→ Enter
  → 主 Agent 路由到 TaskAgent
  → 前端看到「生成中...」→ 流式输出「已创建待办...」
  → 待办页 /todos 可看到新待办
```

### 3.3 记住信息

```
输入「记住我喜欢喝少糖咖啡」→ Enter
  → 主 Agent 路由到 MemoryAgent
  → 流式输出「已记住...」
  → 记忆页 /memories 可看到「沟通偏好」Tab 下有新记忆
```

### 3.4 联网搜索

```
输入「搜索今天有什么科技新闻」→ Enter
  → 主 Agent 路由到 SearchAgent
  → 流式输出带引用的搜索结果
```

## 4. 记忆管理

```
打开 /memories
  → 四个 Tab：基本信息 / 沟通禁忌 / 沟通偏好 / 其他
  → 每个记忆卡片显示：内容 + 分类徽章 + 来源（明确要求/自动提取）
  → 操作：
     ├─ 编辑（Pencil 图标）→ 修改 value + 分类 → 保存
     └─ 删除（Trash 图标）→ Dialog 二次确认 → 删除
```

## 5. 待办与提醒管理

```
打开 /todos
  → 顶部：新建待办输入框 + 添加按钮
  → 提醒区：提醒列表（标题 + 时间 + 状态徽章）
  → 待办区：待办列表
     ├─ 勾选圆圈 → 完成（line-through）
     └─ Trash 图标 → 取消（Dialog 确认）
```

## 6. 提醒触达体验

```
设置提醒「5分钟后提醒我喝水」
  → 到点后：
     1. 站内 toast 弹出「⏰ 喝水」
     2. 浏览器通知（首次会请求权限）
     3. 邮件（配置 SMTP 后）
```

## 7. 模型切换

```
聊天页左下角模型选择器
  → 点击展开下拉
  → 选择「DeepSeek V4 Flash（快）」或「DeepSeek V4 Pro（强）」
  → 后续对话使用所选模型
```

## 8. 退出登录

```
左侧栏底部「退出登录」
  → 清除 session
  → 跳转 /login
```
